# 统一详情页视觉改造设计

## 目标

将足球俱乐部管理系统的前台详情页和后台“查看”模式统一为截图所示的清爽信息卡片：浅灰蓝页面背景、细描边白色主卡片、明确的标题层级、封面媒体区、关键信息区和独立的正文详情区。

本次仅改展示层；既有 REST 接口、字段、权限、数据写入和列表跳转行为保持不变。

## 覆盖范围

- 前台：`gonggao`、`hetong`、`jiaolian`、`saishi`、`shuju`、`xunlian`、`yonghu` 的 `detail.html`。
- 后台：上述业务模块在 `type === 'info'` 时展示的详情模式；编辑、新增模式继续使用现有可编辑表单。
- 配置、字典和管理员等纯配置型页面不纳入这次的图文详情卡改造，只保留全局表单主题。

## 视觉与布局

1. 页面使用柔和灰蓝背景，内容区限制在舒适的最大宽度；手机端自动改为单列。
2. 主卡片采用白底、淡蓝细边框与适度圆角。上方放置页面路径或紧凑工具栏，避免原先大面积渐变横幅。
3. 有图片的实体使用左图右文双栏：图片为固定比例的圆角封面；右侧依次展示分类标签、标题、编号/状态标签和信息行。
4. 无封面的公告、训练等实体改为全宽信息头：标签、标题和关键元数据后接字段网格。
5. 正文、富文本、备注、视频等内容统一置于带分隔线的“详情内容”区；富文本图片保持自适应宽度。
6. 字段采用“中文标签 // 英文语义”式的弱化标签与右侧/下方的醒目值，保证中文业务信息优先可读。
7. 返回与保存操作收束到卡片底部。后台查看模式只显示返回，编辑模式维持现有保存/取消行为。

## 实现边界

### 前台

- 新增一份共享详情样式，供全部 `detail.html` 引用，移除各页相互漂移的内嵌主题定义。
- 每页仅保留模块专属的字段映射、封面来源和正文标题；空图片使用既有默认图，不制造假数据。
- 保留当前 `layui.http` 请求、URL 的 `id` 参数、富文本图片地址修复和列表/返回链接。

### 后台

- 抽出一个可复用的 Vue 详情展示组件或同级结构，接收标题、标签、封面、字段数组与正文 HTML。
- 在业务模块的 `type === 'info'` 分支使用该组件；新增/编辑仍渲染现有 `el-form`。
- 以全局 SCSS 提供统一卡片、字段网格、封面与响应式规则，模块文件只负责字段内容。

## 兼容性与异常处理

- 所有可选字段均提供“暂无”回退；不渲染空标签行。
- 图片加载失败时退回默认封面或占位区域，避免破图图标。
- 长标题、联系方式和富文本图片可换行/缩放，不撑破卡片。
- 视图宽度低于 900px 时，前后台均转换为一列布局；操作按钮不溢出。

## 验收标准

- 赛事 `id=517` 的前台详情呈现为封面 + 结构化信息 + 正文卡片，视觉层次接近参考图而非旧式表单堆叠。
- 后台赛事“查看”页面呈现同一信息卡风格，编辑页面仍可正常保存。
- 其余六个前台详情页与对应后台业务详情均复用相同视觉系统，字段完整可见。
- 前台静态资源无需构建；后台 `npm run build` 成功且产物可正常加载。
